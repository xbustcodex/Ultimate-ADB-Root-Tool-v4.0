A comprehensive GUI tool for Android device rooting, backup, and management with ADB/Fastboot.

## Features

- **Complete Device Backup** - Backup boot images, app data, and user files
- **Rooting Solutions** - Magisk, KernelSU, and APatch support
- **Brand-Specific Tools** - Samsung (Odin), Xiaomi (Mi Flash), Qualcomm, MediaTek
- **Advanced ADB Tools** - Screen recording, logcat, file management
- **USB Driver Management** - Automatic driver installation
- **Backup Management** - Visual backup browser and cleanup
- **Device Information** - Detailed hardware and software scanning
- **Safety Features** - Warnings and confirmations for dangerous operations
